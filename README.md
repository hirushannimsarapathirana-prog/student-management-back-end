# 🎓 Student Management System

A simple and structured **Student Management System** developed to manage student information through a backend application. This project was created to practice Java application development, CRUD operations, database concepts, and web-based system development.

## 📌 Project Overview

The **Student Management System** provides a foundation for managing student records in a centralized system.

The project is designed with a clear separation between the application logic and the user interface, making it easier to maintain and extend in the future.

### ✨ Main Objectives

* Manage student information
* Add new student records
* View student information
* Update existing student records
* Delete student records
* Practice CRUD operations
* Understand backend application architecture
* Connect frontend functionality with backend services

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/hirushannimsarapathirana-prog/student-management-back-end.git
```

### 2. Open the Project

Open the project using **IntelliJ IDEA**.

Make sure Maven recognizes the `pom.xml` file correctly.

### 3. Build the Project

Using Maven:

```bash
mvn clean install
```

### 4. Run the Application

Run the main Java application from IntelliJ IDEA.
